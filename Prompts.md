# Prompts Used in Sprint 02

## Prompt 1
Help me build a Salary and Expense Tracker using HTML, CSS, and Vanilla JavaScript.

## Prompt 2
Implement dynamic DOM manipulation for rendering expenses and salary updates.

## Prompt 3
Add validation to prevent empty and negative inputs.

## Prompt 4
Implement LocalStorage functionality to persist salary and expenses after page reload.

## Prompt 5
Create delete functionality for removing expenses dynamically.

## Prompt 6
Integrate Chart.js to display Remaining Balance vs Total Expenses using a Pie Chart.

## Prompt 7
Implement PDF report download functionality using jsPDF.

## Prompt 8
Add a currency conversion feature using the Frankfurter API for INR, USD, and EUR conversion.

## Prompt 9
Implement threshold warning alerts when remaining balance drops below 10% of salary.

## Prompt 10
Optimize chart rendering using chart.destroy() before re-rendering.
