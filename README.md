# Cash Flow Tracker

A responsive Salary & Expense Tracker built using HTML, CSS, and Vanilla JavaScript.

This project was developed as part of Sprint 02 for Prodesk IT Engineering Division.

---

# Features

## Phase 1 Features
- Add Total Salary
- Add Expenses Dynamically
- Real-Time Remaining Balance Calculation
- Input Validation for Empty/Negative Values

## Phase 2 Features
- LocalStorage Persistence
- Delete Expense Functionality
- Dynamic Pie Chart using Chart.js

## Phase 3 Features
- PDF Report Download using jsPDF
- Currency Conversion API Integration
- Threshold Warning Alerts

---

# Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- jsPDF
- Frankfurter Currency Exchange API
